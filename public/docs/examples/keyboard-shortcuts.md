# 键盘快捷键

> **功能概述**：掌握 iFlow CLI 的键盘快捷键，提升操作效率
> 
> **学习时间**：5-10分钟
> 
> **前置要求**：已安装并配置 iFlow CLI

## 快捷键总览

iFlow CLI 提供丰富的键盘快捷键，帮助您更高效地使用 CLI。本指南详细介绍了所有可用的快捷键及其使用场景。

## 基础快捷键

### 命令操作

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl/Cmd + C` | 取消操作 | 取消当前输入或生成 |
| `Ctrl/Cmd + D` | 退出程序 | 退出 CLI 会话 |
| `Ctrl/Cmd + L` | 清屏 | 清空终端屏幕 |
| `↑/↓` | 历史命令 | 浏览命令历史 |

### 输入相关

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl/Cmd + V` | 粘贴内容 | 自动检测图片、文本 |
| `\` + `Enter` | 多行输入 | 反斜杠换行 |
| `Shift/Option + Enter` | 多行输入 | 根据终端配置 |

## Vim 模式

使用 `/vim` 命令启用 Vim 模式后支持：

| 按键 | 功能 | 说明 |
|------|------|------|
| `h` | 光标左移 | 向左移动一个字符 |
| `j` | 光标下移 | 向下移动一行 |
| `k` | 光标上移 | 向上移动一行 |
| `l` | 光标右移 | 向右移动一个字符 |
| `dd` | 删除行 | 删除当前行 |
| `x` | 删除字符 | 删除当前字符 |

## 常见场景

### 文本编辑

*   使用 `Ctrl/Cmd + V` 快速粘贴代码片段
*   使用 `\` + `Enter` 创建多行代码块
*   使用 `↑/↓` 快速回顾之前的命令

### 快速导航

*   使用 `Ctrl/Cmd + L` 清屏后重新开始对话
*   使用 `Ctrl/Cmd + D` 快速退出当前会话

### 多模态操作

*   使用 `Ctrl/Cmd + V` 粘贴截图或图片
*   使用 `Shift/Option + Enter` 在长文本中快速换行

## 最佳实践

### 组合使用快捷键

*   在输入复杂问题时，先使用 `\` + `Enter` 创建多行输入
*   粘贴大量代码后，使用 `Ctrl/Cmd + L` 清屏查看完整上下文

### 提高效率

*   熟练掌握历史命令快捷键，快速重复之前的操作
*   使用 Vim 模式进行快速文本编辑

## 故障排除

### 快捷键不响应

**可能原因：**

1. 终端配置冲突
2. 快捷键被其他程序占用
3. Vim 模式未启用

**解决方案：**

1. 检查终端设置，确保快捷键未被修改
2. 尝试使用其他快捷键组合
3. 使用 `/vim` 命令启用 Vim 模式（如果需要）

### 多行输入问题

**可能原因：**

1. 终端不支持某些快捷键
2. 配置文件设置错误

**解决方案：**

1. 尝试不同的换行快捷键组合
2. 检查 `iflow.json` 配置文件中的输入设置

## 平台差异

### Windows

*   默认使用 `Ctrl` 和 `Alt` 作为修饰键
*   部分快捷键可能与系统快捷键冲突

### macOS

*   默认使用 `Cmd` 和 `Option` 作为修饰键
*   部分快捷键可能与系统快捷键冲突

### Linux

*   默认使用 `Ctrl` 和 `Alt` 作为修饰键
*   支持自定义快捷键配置

## 进阶技巧

### 自定义快捷键

通过配置文件可以自定义快捷键行为（需查阅相关文档）。

### 终端集成

建议使用支持快捷键的现代化终端（如 Windows Terminal、iTerm2、VS Code Terminal），以获得最佳体验。
