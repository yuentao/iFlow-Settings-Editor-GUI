## 一、P0 级别问题（严重 - 崩溃、数据丢失、安全漏洞）

### P0-01: crypto.randomUUID() 引用错误

| 项目 | 内容 |
|------|------|
| **位置** | `src/main/services/iflowService.js:10` |
| **严重级别** | P0 |
| **问题描述** | `const { crypto } = require('crypto')` 是错误的解构方式，导致 iFlow Mod 导入功能可能崩溃 |

**问题代码**:

```javascript
const { app } = require('electron')
// ...
const { crypto } = require('crypto')  // 错误！

function generateId() {
  return crypto.randomUUID()  // 报错: crypto.randomUUID is not a function
}
```

**验证结果**:

```bash
$ node -e "const { crypto } = require('crypto'); console.log(crypto.randomUUID())"
TypeError: Cannot read properties of undefined (reading 'randomUUID')
```

**影响**: 当导入的 Mod 包没有自带 ID 时，会调用 `generateId()` 生成 ID，此时会报错导致 Mod 导入失败。

**为什么没触发**: 大多数 Mod 包都自带 ID（mod.json 中包含 id 字段），所以 `generateId()` 很少被调用。

**建议修复**:

```javascript
const crypto = require('crypto')  // 改为直接 require
```

## 二、P1 级别问题（重要 - 功能性、错误处理、性能、用户体验）

### P1-01: Vue 组件卸载时未取消正在进行的网络请求

| 项目 | 内容 |
|------|------|
| **位置** | `src/views/ApiConfig.vue:167-172` |
| **严重级别** | P1 |
| **问题描述** | stopPolling 只清理了 interval 定时器，未取消正在进行的 ping 请求 |

**问题代码**:

```javascript
function stopPolling() {
  if (connectivityTimer) {
    clearInterval(connectivityTimer)
    connectivityTimer = null
  }
  // 缺少：取消正在进行的 ping 请求
}
```

**影响**: 当用户快速切换页面时，组件卸载后 ping 请求仍会在后台执行，可能导致：
1. 内存泄漏（请求回调仍在内存中）
2. 尝试更新已卸载组件的响应式数据
3. 不必要的网络请求

**建议修复**:

```javascript
let abortController = null

async function pingProfile(name) {
  abortController = new AbortController()
  const result = await window.electronAPI.pingApiProfile(url)
  // ...
}

function stopPolling() {
  if (connectivityTimer) {
    clearInterval(connectivityTimer)
    connectivityTimer = null
  }
  if (abortController) {
    abortController.abort()
    abortController = null
  }
}
```

## 三、代码质量观察（正向反馈）

代码库整体质量较高，有以下优点：

1. **良好的错误处理**: 大多数 IPC 处理器都使用 `wrapIpcHandler` 包装，返回标准格式的错误
2. **路径安全**: 关键操作都使用了 `isPathSafe` 进行路径遍历防护
3. **加密实现**: 使用了 PBKDF2（600000 次迭代）符合 OWASP 建议
4. **配置备份**: 写入配置前会创建 `.bak` 备份文件
5. **模块化设计**: IPC 处理器按功能模块拆分，代码结构清晰
