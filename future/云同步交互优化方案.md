# iFlow Settings Editor - 云同步交互优化方案

**版本目标**: v1.15.x
**编写日期**: 2026-05-03
**基于版本**: v1.14.8

---

## 一、现状问题分析

### 1.1 当前开启云同步的完整步骤

用户首次使用云同步，需要经历以下操作：

1. 打开「云同步」总开关
2. 因为没设置同步密码，自动弹出密码设置对话框 → 设置密码 + 确认密码
3. 手动找到「云服务配置」卡片 → 选择 WebDAV → 填写 URL / 用户名 / 密码
4. 点击「测试连接」→ 等待结果 → 再点「确认」保存
5. 手动点击「立即同步」→ 又弹出密码输入框 → 输入刚才设的密码
6. 如果想开自动同步 → 再次弹出密码输入框 → 又输一次密码

**最少 6 步，涉及 3 次密码输入，2 个不同概念（WebDAV 密码 vs 同步加密密码）。**

### 1.2 核心痛点

| 痛点 | 表现 | 影响 |
|------|------|------|
| 两套密码概念混淆 | WebDAV 登录密码和同步加密密码在 UI 上没有清晰区分 | 用户困惑，经常填错 |
| 步骤碎片化 | 配置 WebDAV → 测试 → 保存 → 设密码 → 开自动同步，流程割裂 | 用户不知道下一步该做什么 |
| 重复验证密码 | 开自动同步时即使已有缓存密码也要再输一次 | 体验繁琐，3 次密码输入 |
| 状态依赖不明确 | 总开关开了但没配 WebDAV 或没设密码，显示"就绪"但实际无法同步 | 虚假安全感 |
| 缺少引导 | 首次使用没有步骤引导，靠用户自己摸索 | 上手成本高 |

---

## 二、优化方案

本方案包含 4 个互补的改动点，共同解决上述问题。

### 2.1 引导式设置向导

**目标**：首次开启同步时，用分步引导把必要配置串成一个流程。

**改动范围**：`GeneralSettings.vue`（模板 + 逻辑）

**具体设计**：

当用户首次开启云同步开关时，若未完成配置（`!isConfigured`），展开引导面板，分 2 步完成：

```
┌─────────────────────────────────────────────────┐
│  云同步设置向导                                    │
│                                                   │
│  ● 步骤 1: 连接云服务         ✓ 已完成            │
│  ○ 步骤 2: 设置同步密码       → 当前步骤          │
│                                                   │
│  ─────────────────────────────────────────────── │
│                                                   │
│  步骤 2: 设置同步密码                              │
│  同步密码用于加密你的配置数据，与 WebDAV 登录密码无关  │
│                                                   │
│  新密码:    [________________]                     │
│  确认密码:  [________________]                     │
│                                                   │
│              [完成设置]                             │
│                                                   │
│  💡 提示：同步密码无法找回，请妥善保管               │
└─────────────────────────────────────────────────┘
```

**步骤定义**：

| 步骤 | 内容 | 完成条件 | 完成后动作 |
|------|------|----------|-----------|
| 1 | 连接云服务（WebDAV 配置） | `isAuthorized === true` | 自动进入步骤 2 |
| 2 | 设置同步密码 | `hasPassword === true` | 关闭向导，显示正常同步面板 |

**交互逻辑**：

- 开启总开关时，若 `!isConfigured`：展开向导面板（而非当前空白的同步面板）
- 向导步骤 1 内嵌 WebDAV 配置表单（复用现有表单字段），测试连接成功后自动保存并进入步骤 2
- 向导步骤 2 内嵌同步密码设置表单（复用现有密码对话框的字段），设置成功后关闭向导
- 向导完成后，切换为正常同步面板（状态栏 + 立即同步 + 自动同步）
- 若用户关闭总开关再重新开启，且 `isConfigured` 已为 true，直接显示正常面板（不重复向导）
- 向导中可随时关闭总开关退出

**代码改动要点**：

```vue
<!-- GeneralSettings.vue 模板 -->
<div class="section-body" v-show="syncEnabled">
  <!-- 向导模式：未完成配置时 -->
  <CloudSyncWizard v-if="!cloudStore.isConfigured"
    @complete="onWizardComplete"
    @cancel="onWizardCancel"
  />
  <!-- 正常模式：已完成配置 -->
  <template v-else>
    <!-- 现有的状态栏 + 同步操作 + 云服务配置 + 密码管理 + 设备管理 -->
  </template>
</div>
```

```js
// GeneralSettings.vue 逻辑
function onWizardComplete() {
  // 向导完成，loadStatus 刷新状态，面板自动切换到正常模式
  cloudStore.loadStatus()
}

function onWizardCancel() {
  // 用户取消向导，关闭总开关
  cloudStore.setSyncEnabled(false)
}
```

**组件拆分**：

- 新建 `src/components/CloudSyncWizard.vue` 组件，包含向导步骤逻辑
- 向导内部复用现有的 WebDAV 表单字段和密码设置字段，不新建独立表单
- 步骤状态通过组件内部 `currentStep` ref 管理

### 2.2 自动同步免去重复密码验证

**目标**：开启自动同步时，如果已有缓存密码，直接使用，不再弹框。

**改动范围**：`GeneralSettings.vue`（`onToggleAutoSync` 函数）

**当前逻辑**：

```js
async function onToggleAutoSync() {
  const enabled = !cloudStore.autoSyncEnabled
  if (enabled) {
    // 无论是否有缓存密码，都弹框要求输入
    syncPasswordDialog.value = { show: true, ... }
  }
}
```

**优化后逻辑**：

```js
async function onToggleAutoSync() {
  const enabled = !cloudStore.autoSyncEnabled
  if (enabled) {
    if (cloudStore.cachedPassword) {
      // 有缓存密码，直接使用，跳过弹框
      const syncResult = await cloudStore.setAutoSync(true)
      if (syncResult.success) {
        cloudStore.setAutoSyncEnabled(true)
      } else {
        // 设置失败（可能是缓存密码过期），回滚并提示
        cloudStore.setAutoSyncEnabled(false)
        showCloudMessage({ type: 'error', ... })
      }
    } else {
      // 无缓存密码，弹框验证（保持现有逻辑）
      syncPasswordDialog.value = { show: true, ... }
    }
  }
}
```

**注意事项**：

- 缓存密码可能过期（用户在其他设备改了密码），`setAutoSync` 失败时需要提示用户
- 失败后不清除缓存密码（可能只是网络问题），让用户手动触发同步来验证

### 2.3 状态分层显示

**目标**：不同配置阶段显示不同的状态提示，明确告知用户下一步该做什么。

**改动范围**：`GeneralSettings.vue`（状态栏区域）

**当前逻辑**：

状态只有 `statusClass` / `statusLabel` 两个计算属性，基于 `isConfigured`、`isSyncing`、`lastSyncError` 判断，但无法区分"未配 WebDAV"和"未设密码"。

**优化后状态定义**：

| 状态 | 条件 | 状态点颜色 | 状态文本 | 引导提示 |
|------|------|-----------|---------|---------|
| 未配置 | `!isAuthorized && !hasPassword` | 灰色 | "未配置" | "请完成云服务连接和同步密码设置" |
| 半配置-缺密码 | `isAuthorized && !hasPassword` | 黄色 | "未设密码" | "请设置同步密码以启用加密同步" |
| 半配置-缺服务 | `!isAuthorized && hasPassword` | 黄色 | "未连接云服务" | "请配置 WebDAV 服务以开始同步" |
| 已配置-就绪 | `isConfigured && !lastSyncError` | 绿色 | "就绪" | "点击「立即同步」或开启自动同步" |
| 同步中 | `isSyncing` | 蓝色(动画) | "同步中…" | — |
| 同步错误 | `isConfigured && lastSyncError` | 红色 | "同步失败" | 显示错误信息 + 重试按钮 |
| 已禁用 | `!syncEnabled && isConfigured` | 灰色 | "已暂停" | "同步功能已关闭，配置已保留" |

**代码改动要点**：

```js
// GeneralSettings.vue
const cloudSetupPhase = computed(() => {
  if (!cloudStore.status.isAuthorized && !cloudStore.status.hasPassword) return 'unconfigured'
  if (cloudStore.status.isAuthorized && !cloudStore.status.hasPassword) return 'missingPassword'
  if (!cloudStore.status.isAuthorized && cloudStore.status.hasPassword) return 'missingProvider'
  return 'configured'
})

const statusClass = computed(() => {
  if (!syncEnabled.value) return 'status-disabled'
  if (cloudStore.isSyncing) return 'status-syncing'
  if (cloudSetupPhase.value === 'unconfigured') return 'status-unconfigured'
  if (cloudSetupPhase.value === 'missingPassword' || cloudSetupPhase.value === 'missingProvider') return 'status-incomplete'
  if (cloudStore.status.lastSyncError) return 'status-error'
  return 'status-ready'
})

const nextStepHint = computed(() => {
  switch (cloudSetupPhase.value) {
    case 'unconfigured': return t('cloudSync.hintConfigure')
    case 'missingPassword': return t('cloudSync.hintSetPassword')
    case 'missingProvider': return t('cloudSync.hintConnectProvider')
    default: return null
  }
})
```

```vue
<!-- 模板：状态栏增加引导提示 -->
<div class="cloud-status-bar">
  <div class="cloud-status-left">
    <div class="status-indicator" :class="statusClass">
      <span class="status-dot"></span>
      <span class="status-label">{{ statusLabel }}</span>
    </div>
    <span class="next-step-hint" v-if="nextStepHint">{{ nextStepHint }}</span>
    <!-- ... -->
  </div>
</div>
```

**新增 i18n 键**：

```js
// zh-CN
cloudSync: {
  hintConfigure: '请完成云服务连接和同步密码设置',
  hintSetPassword: '请设置同步密码以启用加密同步',
  hintConnectProvider: '请配置 WebDAV 服务以开始同步',
  statusUnconfigured: '未配置',
  statusMissingPassword: '未设密码',
  statusMissingProvider: '未连接云服务',
  statusPaused: '已暂停',
}
```

### 2.4 WebDAV 配置与同步密码合并

**目标**：在正常模式（非向导）下，将 WebDAV 配置和同步密码设置合并到同一卡片区域，减少视觉跳转。

**改动范围**：`GeneralSettings.vue`（模板布局调整）

**当前布局**（3 张独立卡片）：

```
┌─ 状态 + 立即同步 ──────────┐
│  状态指示器  │  自动同步开关  │
│  立即同步按钮               │
│  同步内容标签               │
└────────────────────────────┘

┌─ 云服务配置 ───────────────┐
│  WebDAV URL / 用户名 / 密码 │
│  测试连接 / 保存            │
└────────────────────────────┘

┌─ 同步密码 + 设备管理 ──────┐
│  密码状态 / 设置密码         │
│  记住密码开关               │
│  ── 分隔线 ──              │
│  设备名称 / 设备列表         │
└────────────────────────────┘
```

**优化后布局**（2 张卡片）：

```
┌─ 状态 + 立即同步 ──────────┐
│  状态指示器 + 引导提示       │
│  自动同步开关  │  立即同步    │
│  同步内容标签               │
└────────────────────────────┘

┌─ 云同步配置 ───────────────┐
│  ┌─ 云服务连接 ───────────┐ │
│  │  WebDAV URL / 用户名    │ │
│  │  WebDAV 密码 (标注)     │ │
│  │  测试 / 保存            │ │
│  └────────────────────────┘ │
│  ┌─ 同步加密 ─────────────┐ │
│  │  密码状态 / 设置密码     │ │
│  │  记住密码开关            │ │
│  └────────────────────────┘ │
│  ┌─ 设备管理 ─────────────┐ │
│  │  设备名称 / 设备列表     │ │
│  └────────────────────────┘ │
└────────────────────────────┘
```

**关键改动**：

1. 合并「云服务配置」和「同步密码 + 设备管理」为一张卡片「云同步配置」
2. 卡片内部用子区块分隔，每个子区块有小标题
3. WebDAV 密码字段旁增加标注：`（用于登录 WebDAV 服务）`
4. 同步密码区域标注：`（用于加密同步数据，与 WebDAV 密码无关）`
5. 设备管理保留在卡片底部，用分隔线隔开

**WebDAV 密码字段的标注**：

```vue
<div class="form-group">
  <label class="form-label">
    {{ $t('cloudSync.webdavPassword') }}
    <span class="form-label-hint">{{ $t('cloudSync.webdavPasswordHintTag') }}</span>
  </label>
  <input type="password" class="form-input" v-model="webdavConfig.password" />
</div>
```

**新增 i18n 键**：

```js
// zh-CN

  webdavPasswordHintTag: '（WebDAV 登录密码）',
  syncPasswordHintTag: '（加密同步数据，与 WebDAV 密码无关）',

  configSectionEncryption: '同步加密',
  configSectionDevices: '设备管理',
```

## 四、实施顺序

按依赖关系排序，每个步骤独立可测试：

1. **状态分层显示**（2.3）— 纯计算属性 + 模板改动，无新组件，风险最低
2. **自动同步免去重复验证**（2.2）— 单函数逻辑改动，独立可测试
3. **WebDAV 配置与同步密码合并**（2.4）— 纯布局调整，不涉及逻辑
4. **引导式设置向导**（2.1）— 依赖前三步完成后才能集成，最后实施

## 五、验收标准

1. 首次开启云同步，向导自动弹出，2 步完成配置
2. 向导完成后，面板自动切换为正常模式
3. 开启自动同步时，若有缓存密码，不弹框直接启用
4. 未配置 / 半配置 / 已配置三种状态有明确的视觉区分和引导提示
5. WebDAV 密码和同步密码在 UI 上有清晰标注，不再混淆
6. 现有功能（手动同步、设备管理、清空云端等）不受影响
7. 三语言（中/英/日）的 i18n 键全部补齐
