## 🎯 方案概述

### 核心目标

1. **增量更新优先**: 默认启用差分更新，平均下载大小从 **60 MB 降至 <15 MB**
2. **无缝回退**: 差分更新失败时自动降级为完整包更新
3. **向后兼容**: 旧版本客户端仍能正常更新
4. **用户可控**: 设置页面提供增量更新开关
5. **数据可观测**: 本地统计 + 可选匿名上报

### 技术选型

**方案**: 使用 `electron-updater@6.8.3` 内置的 **blockMap 差分算法**

**优势**:
- ✅ 零服务器成本（复用 GitHub Releases API）
- ✅ 构建时自动生成 `.blockmap` 和 `.delta` 文件
- ✅ 客户端自动识别差分/完整更新
- ✅ 内置回退机制（失败自动降级）
- ✅ 签名验证（SHA256 + PGP）

### 1.1 重写 `src/main/autoUpdater.js`

**目标**: 用 `electron-updater` 官方 API 完全替换自定义实现

**完整代码**:

```javascript
// src/main/autoUpdater.js
const { app } = require('electron')
const { autoUpdater } = require('electron-updater')
const { logger } = require('./utils/logger')
const { readSettings, writeSettings } = require('./services/configService')

// 主窗口引用（弱引用，避免循环）
let mainWindowRef = null

// 更新状态（与渲染进程同步）
let updateState = {
  status: 'idle', // idle | checking | available | downloading | downloaded | error
  info: null,
  progress: 0,
  error: null,
  downloadPath: null,
  isBackground: false,
  isDelta: false, // 🔥 新增：是否为增量更新
  deltaSaving: 0, // 🔥 新增：节省的字节数
}

/**
 * 初始化自动更新器
 * @param {Function} getMainWindow - 获取主窗口的函数
 * @param {Object} options - 配置选项
 */
function initAutoUpdater(getMainWindow, options = {}) {
  mainWindowRef = getMainWindow

  // 🔥 关键配置：启用增量更新
  autoUpdater.enableDeltaUpdates = true
  autoUpdater.deltaUpdateStrategy = 'blockMap' // 使用 blockMap 算法

  // 手动控制下载流程（不自动下载）
  autoUpdater.autoDownload = false
  autoUpdater.autoInstallOnAppQuit = false

  // 不允许降级（安全考虑）
  autoUpdater.allowDowngrades = false
  autoUpdater.allowPrerelease = false

  // 设置日志
  autoUpdater.logger = logger
  autoUpdater.logger.transports.file.level = 'info'

  // 绑定事件
  bindEvents()

  logger.info('[AutoUpdater] Initialized with delta updates enabled')
}

/**
 * 绑定 electron-updater 事件
 */
function bindEvents() {
  // 开始检查更新
  autoUpdater.on('checking-for-update', () => {
    updateState.status = 'checking'
    updateState.error = null
    notifyRenderer('update-status-changed', updateState)
  })

  // 发现新版本
  autoUpdater.on('update-available', (info) => {
    updateState.status = 'available'
    updateState.info = {
      version: info.version,
      releaseNotes: info.releaseNotes,
      releaseUrl: info.releaseUrl,
      downloadUrl: info.downloadUrl,
      downloadName: info.downloadName,
      size: info.size,
      isDelta: info.delta || false, // 🔥 关键：是否为差分包
      fullSize: info.fullSize || info.size, // 完整包大小
    }
    updateState.isDelta = info.delta || false
    updateState.deltaSaving = info.delta && info.fullSize
      ? info.fullSize - (info.size || 0)
      : 0

    notifyRenderer('update-status-changed', updateState)
    notifyRenderer('update-available', updateState.info)
  })

  // 无更新
  autoUpdater.on('update-not-available', () => {
    updateState.status = 'idle'
    notifyRenderer('update-status-changed', updateState)
  })

  // 下载进度
  autoUpdater.on('download-progress', (progress) => {
    updateState.status = 'downloading'
    updateState.progress = Math.round(progress.percent)
    updateState.isDelta = progress.isDelta || false

    notifyRenderer('update-download-progress', updateState.progress)
    notifyRenderer('update-status-changed', updateState)
  })

  // 下载完成
  autoUpdater.on('update-downloaded', (info) => {
    updateState.status = 'downloaded'
    updateState.downloadPath = info.downloadPath
    updateState.isDelta = info.delta || false
    updateState.deltaSaving = info.delta && info.fullSize
      ? info.fullSize - (info.downloadSize || 0)
      : 0

    // 🔥 持久化待安装更新信息（应用重启后仍保留）
    const settings = readSettings()
    settings.pendingUpdate = {
      version: info.version,
      downloadPath: info.downloadPath,
      downloadName: info.downloadName,
      isDelta: info.delta,
      fullSize: info.fullSize,
      downloadSize: info.downloadSize,
    }
    writeSettings(settings)

    // 🔥 记录更新统计
    recordUpdateMetrics('download_complete', {
      fromVersion: getCurrentVersion(),
      toVersion: info.version,
      updateType: info.delta ? 'delta' : 'full',
      downloadSize: info.downloadSize || 0,
      fullSize: info.fullSize || 0,
      success: true,
    })

    notifyRenderer('update-status-changed', updateState)
    notifyRenderer('update-downloaded', updateState)
  })

  // 下载错误
  autoUpdater.on('download-error', (error) => {
    logger.error('[AutoUpdater] Download error:', error)

    // 🔥 记录失败统计
    recordUpdateMetrics('download_failed', {
      error: error.message,
      isDelta: updateState.isDelta,
    })

    updateState.status = 'error'
    updateState.error = error.message

    // 清除待安装状态
    const settings = readSettings()
    delete settings.pendingUpdate
    writeSettings(settings)

    notifyRenderer('update-status-changed', updateState)
  })

  // 其他错误（包括差分合并失败）
  autoUpdater.on('error', (error) => {
    logger.error('[AutoUpdater] Error:', error)

    // 🔥 检测是否为差分相关错误
    const isDeltaError = error.message.toLowerCase().includes('delta') ||
                        error.message.toLowerCase().includes('patch') ||
                        error.message.toLowerCase().includes('blockmap')

    if (isDeltaError) {
      logger.warn('[AutoUpdater] Delta update failed, falling back to full update')
      recordUpdateMetrics('delta_fallback', {
        error: error.message,
      })

      // 自动降级：清除状态，下次检查会下载完整包
      updateState.status = 'idle'
      updateState.error = null
      updateState.isDelta = false

      // 延迟 2 秒后重新检查（触发完整包下载）
      setTimeout(() => {
        logger.info('[AutoUpdater] Retrying with full update...')
        autoUpdater.checkForUpdates()
      }, 2000)
    } else {
      updateState.status = 'error'
      updateState.error = error.message
    }

    notifyRenderer('update-status-changed', updateState)
  })
}

/**
 * 通知渲染进程
 */
function notifyRenderer(channel, data) {
  const mainWindow = mainWindowRef?.()
  if (mainWindow && mainWindow.webContents) {
    mainWindow.webContents.send(channel, data)
  }
}

/**
 * 检查更新（IPC 调用入口）
 */
async function checkForUpdates() {
  try {
    await autoUpdater.checkForUpdates()
  } catch (error) {
    logger.error('[AutoUpdater] Check failed:', error)
    updateState.status = 'error'
    updateState.error = error.message
    notifyRenderer('update-status-changed', updateState)
  }
}

/**
 * 下载更新（前台）
 */
async function downloadUpdate() {
  try {
    updateState.status = 'downloading'
    updateState.progress = 0
    notifyRenderer('update-status-changed', updateState)

    await autoUpdater.downloadUpdate()
  } catch (error) {
    if (error.message !== 'Download cancelled') {
      logger.error('[AutoUpdater] Download failed:', error)
      updateState.status = 'error'
      updateState.error = error.message
      notifyRenderer('update-status-changed', updateState)
      throw error
    }
  }
}

/**
 * 后台下载（静默模式）
 */
async function downloadUpdateBackground() {
  updateState.isBackground = true
  notifyRenderer('update-status-changed', updateState)

  try {
    await autoUpdater.downloadUpdate()
  } catch (error) {
    if (error.message !== 'Download cancelled') {
      logger.error('[AutoUpdater] Background download failed:', error)
      updateState.status = 'error'
      updateState.error = error.message
      updateState.isBackground = false
      notifyRenderer('update-status-changed', updateState)
      throw error
    }
  }
}

/**
 * 取消下载
 */
async function cancelDownload() {
  try {
    await autoUpdater.cancelDownload()
    updateState.status = 'idle'
    updateState.progress = 0
    updateState.isBackground = false
    notifyRenderer('update-status-changed', updateState)
  } catch (error) {
    logger.error('[AutoUpdater] Cancel failed:', error)
  }
}

/**
 * 安装更新
 */
async function installUpdate() {
  try {
    // 清除待安装缓存
    const settings = readSettings()
    delete settings.pendingUpdate
    writeSettings(settings)

    // 记录安装事件
    recordUpdateMetrics('install_complete', {
      fromVersion: getCurrentVersion(),
      toVersion: updateState.info?.version,
      updateType: updateState.isDelta ? 'delta' : 'full',
      success: true,
    })

    // 退出并安装
    await autoUpdater.quitAndInstall(false, false)
  } catch (error) {
    logger.error('[AutoUpdater] Install failed:', error)

    recordUpdateMetrics('install_failed', {
      error: error.message,
    })

    throw error
  }
}

/**
 * 获取当前应用版本
 */
function getCurrentVersion() {
  return app.getVersion()
}

/**
 * 获取更新状态
 */
function getUpdateState() {
  return { ...updateState }
}

/**
 * 获取待安装更新
 */
function getPendingUpdate() {
  const settings = readSettings()
  return settings.pendingUpdate || null
}

/**
 * 清除待安装更新
 */
function clearPendingUpdate() {
  const settings = readSettings()
  delete settings.pendingUpdate
  writeSettings(settings)
}

/**
 * 记录更新统计（本地埋点）
 */
function recordUpdateMetrics(event, data) {
  try {
    const { app } = require('electron')
    const fs = require('fs')
    const path = require('path')

    const metricsPath = path.join(app.getPath('userData'), 'update-metrics.json')
    let metrics = { events: [] }

    if (fs.existsSync(metricsPath)) {
      metrics = JSON.parse(fs.readFileSync(metricsPath, 'utf-8'))
    }

    metrics.events.push({
      timestamp: new Date().toISOString(),
      event,
      ...data,
      platform: process.platform,
      arch: process.arch,
      appVersion: app.getVersion(),
    })

    // 保留最近 100 条记录
    if (metrics.events.length > 100) {
      metrics.events = metrics.events.slice(-100)
    }

    fs.writeFileSync(metricsPath, JSON.stringify(metrics, null, 2))
  } catch (error) {
    logger.error('[Metrics] Failed to record event:', error)
  }
}

module.exports = {
  initAutoUpdater,
  checkForUpdates,
  downloadUpdate,
  downloadUpdateBackground,
  cancelDownload,
  installUpdate,
  getUpdateState,
  getPendingUpdate,
  clearPendingUpdate,
  getCurrentVersion,
}
```

### 1.2 创建/修改 `src/main/ipc/updates.js`

**目标**: 提供完整的 IPC 接口，支持增量更新配置和统计查询

**完整代码**:

```javascript
// src/main/ipc/updates.js
const { ipcMain } = require('electron')
const {
  initAutoUpdater,
  checkForUpdates,
  downloadUpdate,
  downloadUpdateBackground,
  cancelDownload,
  installUpdate,
  getUpdateState,
  getPendingUpdate,
  clearPendingUpdate,
  getCurrentVersion,
} = require('../autoUpdater')
const { readSettings, writeSettings } = require('../services/configService')
const { recordUpdateMetrics } = require('../autoUpdater')

// 默认增量更新配置
const DEFAULT_UPDATE_SETTINGS = {
  enableDeltaUpdates: true,
  allowBackgroundDownload: true,
  downloadTimeout: 300,
  maxRetries: 3,
  skipDeltaIfLarger: true,
  notifyOnBackgroundComplete: true,
}

/**
 * 注册更新相关的 IPC 处理器
 */
function registerUpdatesIpcHandlers() {
  // ─── 基础更新操作 ────────────────────────────────────────

  // 检查更新
  ipcMain.handle('check-for-updates', async () => {
    await checkForUpdates()
    return { success: true }
  })

  // 下载更新（前台）
  ipcMain.handle('download-update', async () => {
    await downloadUpdate()
    return { success: true }
  })

  // 后台下载
  ipcMain.handle('download-update-background', async () => {
    await downloadUpdateBackground()
    return { success: true }
  })

  // 取消下载
  ipcMain.handle('cancel-download', async () => {
    await cancelDownload()
    return { success: true }
  })

  // 安装更新
  ipcMain.handle('install-update', async () => {
    await installUpdate()
    return { success: true }
  })

  // 获取更新状态
  ipcMain.handle('get-update-status', () => {
    return { success: true, ...getUpdateState() }
  })

  // 获取待安装更新
  ipcMain.handle('get-pending-update', () => {
    return { success: true, update: getPendingUpdate() }
  })

  // 清除待安装更新
  ipcMain.handle('clear-pending-update', async () => {
    clearPendingUpdate()
    return { success: true }
  })

  // 获取当前版本
  ipcMain.handle('get-app-version', () => {
    return { success: true, version: getCurrentVersion() }
  })

  // ─── 增量更新配置 ────────────────────────────────────────

  // 获取更新设置
  ipcMain.handle('get-update-settings', async () => {
    try {
      const settings = readSettings()
      const updateSettings = settings?.updateSettings || DEFAULT_UPDATE_SETTINGS
      return { success: true, settings: updateSettings }
    } catch (error) {
      return { success: false, error: error.message }
    }
  })

  // 更新更新设置
  ipcMain.handle('set-update-settings', async (event, newSettings) => {
    try {
      const settings = readSettings() || {}
      settings.updateSettings = { ...DEFAULT_UPDATE_SETTINGS, ...newSettings }
      await writeSettings(settings)
      return { success: true }
    } catch (error) {
      return { success: false, error: error.message }
    }
  })

  // ─── 统计查询 ───────────────────────────────────────────

  // 获取增量更新统计
  ipcMain.handle('get-delta-stats', () => {
    try {
      const { app } = require('electron')
      const fs = require('fs')
      const path = require('path')

      const metricsPath = path.join(app.getPath('userData'), 'update-metrics.json')
      if (!fs.existsSync(metricsPath)) {
        return {
          success: true,
          stats: {
            totalUpdates: 0,
            deltaUpdates: 0,
            fullUpdates: 0,
            avgDeltaSize: 0,
            totalSavedBytes: 0,
          },
        }
      }

      const metrics = JSON.parse(fs.readFileSync(metricsPath, 'utf-8'))
      const events = metrics.events || []

      const updates = events.filter(e => e.event === 'download_complete')
      const deltaUpdates = updates.filter(u => u.updateType === 'delta')
      const fullUpdates = updates.filter(u => u.updateType === 'full')

      const avgDeltaSize = deltaUpdates.length > 0
        ? deltaUpdates.reduce((sum, u) => sum + (u.downloadSize || 0), 0) / deltaUpdates.length
        : 0

      const totalSaved = updates.reduce((sum, u) => {
        const fullSize = u.fullSize || u.downloadSize
        const deltaSize = u.downloadSize
        return sum + (fullSize - deltaSize)
      }, 0)

      return {
        success: true,
        stats: {
          totalUpdates: updates.length,
          deltaUpdates: deltaUpdates.length,
          fullUpdates: fullUpdates.length,
          avgDeltaSize,
          totalSavedBytes: totalSaved,
          lastUpdate: updates.length > 0 ? updates[updates.length - 1].timestamp : null,
        },
      }
    } catch (error) {
      return { success: false, error: error.message }
    }
  })

  // 获取详细更新历史
  ipcMain.handle('get-update-history', () => {
    try {
      const { app } = require('electron')
      const fs = require('fs')
      const path = require('path')

      const metricsPath = path.join(app.getPath('userData'), 'update-metrics.json')
      if (!fs.existsSync(metricsPath)) {
        return { success: true, history: [] }
      }

      const metrics = JSON.parse(fs.readFileSync(metricsPath, 'utf-8'))
      const history = (metrics.events || [])
        .filter(e => ['download_complete', 'install_complete'].includes(e.event))
        .map(e => ({
          timestamp: e.timestamp,
          fromVersion: e.fromVersion,
          toVersion: e.toVersion,
          updateType: e.updateType,
          downloadSize: e.downloadSize,
          fullSize: e.fullSize,
          success: e.success,
        }))

      return { success: true, history }
    } catch (error) {
      return { success: false, error: error.message }
    }
  })

  // ─── 诊断接口 ────────────────────────────────────────────

  // 获取增量更新状态（用于调试）
  ipcMain.handle('get-delta-update-status', () => {
    return {
      success: true,
      enabled: autoUpdater?.enableDeltaUpdates,
      strategy: autoUpdater?.deltaUpdateStrategy,
      lastDeltaSuccess: null, // TODO: 从 metrics 中提取
      lastFullDownload: null,
    }
  })

  console.log('[IPC] Updates handlers registered (with delta support)')
}

module.exports = { registerUpdatesIpcHandlers }
```

```javascript
    }
```

```javascript
const { app } = require('electron')

try {
  const userDataPath = app.getPath('userData')
  const updateDir = path.join(userDataPath, '..', '..', 'update') // electron-updater 缓存目录

  if (fs.existsSync(updateDir)) {

    console.log(`Found ${files.length} files in update cache:`)

      console.log(`  ✅ Deleted: ${f}`)
    })

    console.log('\n✅ Update cache cleaned successfully.')
  } else {
    console.log('ℹ️  No update cache found.')

    }
```

```javascript
    const deltas = files.filter(f => f.endsWith('.delta'))

      console.log(`✅ Found ${deltas.length} delta file(s): ${deltas.join(', ')}`)
    } else {

  }
}

runTests().catch(error => {

})
```

### 4.2 统计计算函数

**文件**: `src/main/services/updateMetrics.js`（已集成到 autoUpdater.js 中）

**核心函数**:

```javascript
/**
 * 获取统计摘要
 */
function getStats() {
  const metrics = loadMetrics()
  const events = metrics.events

  const updates = events.filter(e => e.event === 'download_complete')
  const deltaUpdates = updates.filter(u => u.updateType === 'delta')
  const fullUpdates = updates.filter(u => u.updateType === 'full')

  const avgDeltaSize = deltaUpdates.length > 0
    ? deltaUpdates.reduce((sum, u) => sum + (u.downloadSize || 0), 0) / deltaUpdates.length
    : 0

  const totalSaved = updates.reduce((sum, u) => {
    const fullSize = u.fullSize || u.downloadSize
    const deltaSize = u.downloadSize
    return sum + (fullSize - deltaSize)
  }, 0)

  return {
    totalUpdates: updates.length,
    deltaUpdates: deltaUpdates.length,
    fullUpdates: fullUpdates.length,
    avgDeltaSize,
    totalSavedBytes: totalSaved,
    lastUpdate: updates.length > 0 ? updates[updates.length - 1].timestamp : null,
    deltaRatio: updates.length > 0 ? (deltaUpdates.length / updates.length * 100).toFixed(1) + '%' : '0%',
  }
}
```

## ⚠️ Phase 5: 风险评估与应对

### 5.1 风险矩阵

| 风险 | 概率 | 影响 | 等级 | 应对措施 |
|------|------|------|------|----------|
| **差分包合并失败** | 1% | 高 | 🟡 中 | 自动降级完整包 + 错误日志 |
| **blockmap 不匹配** | 5% | 中 | 🟡 中 | 版本严格对齐，强制完整包 |
| **差分包大于完整包** | 1% | 低 | 🟢 低 | `skipDeltaIfLarger` 配置 |
| **网络中断/超时** | 10% | 低 | 🟢 低 | 重试机制（maxRetries） |
| **磁盘空间不足** | 2% | 中 | 🟡 中 | 下载前检查空间（electron-updater 内置） |
| **权限不足** | 1% | 高 | 🟡 中 | UAC 提示，降级处理 |
| **GitHub API 限流** | 5% | 中 | 🟡 中 | 缓存 release info，指数退避 |
| **构建配置错误** | 10% | 高 | 🔴 高 | 预发布检查脚本（test-delta-update.js） |

### 5.2 回滚策略

#### 客户端自动回滚

```javascript
// 在 autoUpdater.js 的 error 事件处理器中
autoUpdater.on('error', (error) => {
  const isDeltaError = error.message.toLowerCase().includes('delta') ||
                       error.message.toLowerCase().includes('patch') ||
                       error.message.toLowerCase().includes('blockmap')

  if (isDeltaError) {
    logger.warn('[AutoUpdater] Delta update failed, falling back to full update')

    // 清除状态
    updateState.status = 'idle'
    updateState.error = null
    updateState.isDelta = false

    // 延迟重试（触发完整包下载）
    setTimeout(() => {
      logger.info('[AutoUpdater] Retrying with full update...')
      autoUpdater.checkForUpdates()
    }, 2000)
  } else {
    // 非差分错误，正常处理
    updateState.status = 'error'
    updateState.error = error.message
  }
})
```

#### 服务端回滚（GitHub Releases）

## ❓ FAQ

### Q1: 为什么有时下载的不是差分包？

**A**: 以下几种情况会下载完整包：
1. **首次安装**: 本地无旧版本 blockmap 文件
2. **版本跨度太大**: 超过 3-5 个版本，可能无直接差分
3. **blockmap 缺失**: 旧版本构建时未启用 `generateBlockmap`
4. **差分包更大**: 配置 `skipDeltaIfLarger: true` 时，差分包 > 完整包 50% 会跳过
5. **网络/CDN 问题**: GitHub Releases CDN 未缓存差分文件

### Q2: 差分包合并失败怎么办？

**A**: 客户端自动处理：
1. 检测到差分合并错误（blockMap 不匹配、校验失败）
2. 自动清除错误状态
3. 延迟 2 秒后重新检查更新（触发完整包下载）
4. 用户无感知，仅下载时间稍长

**日志示例**:
```
[WARN] Delta update failed, falling back to full update
[INFO] Retrying with full update...
```

### Q3: 如何验证差分更新是否生效？

**A**: 检查以下几点：

1. **Release 文件列表**:
   - 应有 `.blockmap` 文件（约 1 MB）
   - 应有 `.delta` 文件（约 5-15 MB，如果存在旧版本 blockmap）

2. **下载文件大小**:
   - 增量更新：下载 5-15 MB（而非 60 MB）
   - 查看下载进度对话框显示的大小

3. **更新历史**:
   ```javascript
   // 在 DevTools 控制台
   const history = await window.electronAPI.getUpdateHistory()
   console.log(history.history[0].updateType) // 应显示 "delta"
   ```

4. **统计面板**（如果添加了）:
   - 增量更新占比 > 80%
   - 累计节省流量显著

### Q4: 可以关闭增量更新吗？

**A**: 可以。两种方式：

1. **全局设置**（推荐）:
   ```
   设置 → 其他设置 → 启用增量更新 [✓] → 关闭
   ```

2. **配置文件**:
   ```json
   {
     "updateSettings": {
       "enableDeltaUpdates": false
     }
   }
   ```

3. **紧急回滚**（临时）:
   ```json
   // package.json
   {
     "build": {
       "publish": {
         "generateDelta": false
       }
     }
   }
   ```

### Q5: 对 CI/CD 有什么要求？

**A**: 需要：

1. **GITHUB_TOKEN 权限**:
   - 需要 `repo` scope（完整仓库权限）
   - 在 GitHub Settings → Developer settings → Personal access tokens 生成

2. **构建命令**:
   ```bash
   npm run publish  # 或 electron-builder --publish always
   ```

3. **版本标签**:
   - 使用语义化版本（如 `v1.17.0`）
   - 标签格式：`v${version}`（由 `vPrefixedTagName: true` 自动处理）

4. **构建环境**:
   - Windows（用于构建 Windows 安装器）
   - macOS（用于构建 macOS dmg，可选）

### Q6: 增量更新支持哪些平台？

**A**: 全平台支持：
- ✅ Windows (nsis / portable)
- ✅ macOS (dmg / zip)
- ✅ Linux (AppImage / deb / rpm)

**注意**: 每个平台/架构需要单独构建，差分文件也是平台相关的。
